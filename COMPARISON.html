Important caveat for fair reading. React and Vue ship a heavyweight component library (AntD / Element Plus) responsible for most of the bundle weight. Solid, Svelte and Qwik run on plain CSS in our examples. With an equivalent UI library, Solid/Svelte would climb to ~80–150 KB gzip — still 2× to 5× lighter than React + AntD, but the gap would be less dramatic. Angular ships with no UI library here, so its 175 KB gzip is the framework alone.

When to pick what

React

  • Your team already knows it. Largest library ecosystem.
  • Avoid for tiny custom pages or weak networks.

Vue 3

  • Comfortable with <script setup>. Balanced ecosystem (Element Plus / Naive UI / PrimeVue).
  • Conservative release policy — stable.

Angular

  • Enterprise environment with full kit (router, DI, signals, forms) without 5 extra deps.
  • 6-month release cadence; expect periodic refactoring (signals migration recently).
  • Smallest "batteries included" option of the six.

Svelte 5

  • Minimal bundle, "HTML-like" syntax. Best all-rounder for NEW Bonita pages.
  • Easier hiring than Solid or Qwik.

SolidJS

  • Performance is a hard requirement (massive lists, real-time dashboards).
  • You like JSX but hate React's bundle size.
  • Smaller ecosystem.

Qwik

  • Heavy page where instant first-paint is critical.
  • You accept a young framework with possible breaking changes 2026-2027.
  • Best when "the page is huge but most users only touch part of it".

Reproduce the measurements

cd ui-bonita-projects
for proj in react-directory-bonita vue-directory-bonita angular-directory-bonita \
           svelte-directory-bonita solid-directory-bonita qwik-directory-bonita; do
  cd "examples/$proj"
  npm install --silent
  npm run dist
  ZIP=$(ls dist/page-*.zip | head -1)
  ZIP_KB=$(($(stat -c%s "$ZIP") / 1024))
  JS_GZIP=$(($(find dist -name "*.js" -exec cat {} + | gzip -9c | wc -c) / 1024))
  echo "$proj  ZIP=${ZIP_KB}KB  JS_gzip=${JS_GZIP}KB"
  cd -
done

Cuándo elegir qué

React

  • Tu equipo ya lo domina. Mayor ecosistema.
  • Evitar para custom pages muy pequeñas o redes lentas.

Vue 3

  • Te gusta <script setup>. Ecosistema equilibrado (Element Plus / Naive UI / PrimeVue).
  • Política conservadora — estable.

Angular

  • Entorno corporativo todo en uno (router, DI, signals, forms).
  • Ciclo de 6 meses; refactor periódico esperado.
  • El más "baterías incluidas" de los seis.

Svelte 5

  • Tamaño mínimo y sintaxis "HTML+JS de toda la vida".
  • Mejor opción para PROYECTOS NUEVOS sin legacy en casa.

SolidJS

  • Rendimiento crítico (listas masivas, dashboards en tiempo real).
  • Te gusta JSX pero no el peso de React.
  • Ecosistema más pequeño.

Qwik

  • Página muy pesada donde el first-paint instantáneo es crítico.
  • Aceptas un framework joven con posibles breaking changes 2026-2027.
