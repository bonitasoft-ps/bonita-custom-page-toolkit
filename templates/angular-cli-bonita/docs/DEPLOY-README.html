English

What you have

  • page-__NAME__.zip — the Bonita custom page (an __FRAMEWORK_LABEL__ SPA)
  • This README and the matching markdown file (informational, do not upload to Bonita)

Prerequisites

  • A running Bonita 2025.x instance
  • An admin user (default Studio: install / install)
  • The host and port of your instance (example: http://localhost:8080)

Step 1 — Login

http://localhost:8080/bonita/login.jsp

Sign in with admin credentials. Replace the host/port with yours.

Step 2 — Upload the page resource

http://localhost:8080/bonita/apps/superAdminAppBonita/resource-list/

Click + Add a resource, select page-__NAME__.zip, confirm. The page appears with displayName __DISPLAY_NAME__.

Tenant admin equivalent: /bonita/apps/adminAppEEBonita/admin-resource-list/

Step 3 — Create a new application

http://localhost:8080/bonita/apps/superAdminAppBonita/application-list/

Click + Create application and fill:

FieldValue
Token__APP_TOKEN__
Display name__DISPLAY_NAME__
Profilethe profile your users have
LayoutLayout Without Menu
Important — pick "Layout Without Menu". The default Bonita layout wraps every page with a header and a side menu. For a full-screen SPA you must select Layout Without Menu so the page fills the entire viewport. This is the most common cause of "the app is squeezed inside the Bonita admin chrome".

Save. Note the application's id (visible in the URL after saving, e.g. id=14).

Step 4 — Bind the page to the application

http://localhost:8080/bonita/apps/superAdminAppBonita/admin-application-details/?id={id}
  1. Open the Pages section
  2. Click + Add page
  3. Select __DISPLAY_NAME__
  4. Set Token to home
  5. Save (optionally mark as the application's Home page)

Step 5 — Open the application

http://localhost:8080/bonita/apps/__APP_TOKEN__/home/?_l=en

The __FRAMEWORK_LABEL__ SPA loads, auto-detects your Bonita session, and shows the task list. Listo.

Updating later

Build a new ZIP with the same page.properties.name. Upload via the same resource-list — Bonita prompts to replace it. Application bindings are preserved. Force-refresh (Ctrl+F5) to bust browser cache.
